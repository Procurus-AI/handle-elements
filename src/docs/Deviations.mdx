# Deviations from Figma

The visual source is Kevin's Figma file "Handle Platform UI — Foundations" (last modified 2026-11-26). The tokens match it except in the places listed here. Each one needs Kevin's sign-off.

## Why tokens come from variable-bound fills

The Foundations page in Figma shows each colour twice: as a swatch bound to a variable, and as a typed label. The two had drifted apart. The generator found 66 differences. The swatch is the live variable, which is what the Figma components render, so `scripts/tokens/build-tokens.mjs` reads the swatch fill and ignores the label.

`npm run tokens -- --check` regenerates `tokens.css` and fails if someone edited it by hand.

Two of the differences matter for how the product looks. The primary accent is Borealis (`#E0FEA2`), not Verde (`#C8F04A`). The dark surfaces are the bluish values from the fills, not the warm neutrals in the labels. The dark status chips also use 800 and 900 steps (for example Success/800 and Success/900) that are not in the primitive swatches. They ship as plain values in the dark theme.

## AA adjustments

## Dark chart-1

In light, `--he-chart-1` is Midnight. On a dark surface Midnight would disappear, so in dark it follows `--he-text-primary`. Kevin's file does not define a dark value for this slot.

## Dark elevation tint

The light shadows are tinted with Midnight at 6%, 10% and 16% opacity. The same shadows are almost invisible on a dark surface. In dark the shadows are black at 21%, 36% and 56%. The offsets and blur values are Kevin's.
