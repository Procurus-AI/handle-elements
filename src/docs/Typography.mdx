# Typography

Three families, 16 styles. Inter is the UI face. Sentient is for page titles. IBM Plex Mono is for machine identifiers. Inter replaces Neue Haas Unica from 0.x.

Each style is a set of five variables: `--he-type-<style>-family`, `-size`, `-line`, `-weight` and `-tracking`. For example, `--he-type-body-md-size`. Components set type from these variables and never from a raw size.

<Rule title="One family per job">
  Sentient only for page titles. Inter for everything else. Plex Mono only for machine identifiers
  such as policy numbers and receipt numbers. Do not use Plex Mono to make text look technical.
</Rule>

## Where each style is used

- **Display** is for the page title only. Page title is 30/36 and Page title sm is 24/30 for narrow views.
- **Heading** names a section or a panel. `lg` for a view section, `md` for a panel, `sm` for a group inside a panel.
- **Body** is running text and table cells. Use the emphasis weight for the one thing in a line that matters.
- **Label** is for buttons, tabs, form labels and badges.
- **Caption** is the smallest text. It is the only style that may be set in capitals, as in "MONTO VENCIDO" above a number.
- **Metric** is for large numbers in stat cells and charts. Numbers use the format in [Content](?path=/docs/foundations-content--docs).
- **Mono** is for identifiers such as `3101-02938188-00`. One size only.

## Fonts

`fonts.css` loads Sentient (Light, Regular), Inter (variable font, weights 300, 400 and 500 are used) and IBM Plex Mono. All three are vendored in the package. The build fails if `fonts.css` points to a file that is missing. Sentient is under the Fontshare free licence. Inter and Plex Mono are under the SIL Open Font Licence.
