# Elevation

There are three levels of elevation. Nothing else casts a shadow.

export const levels = [
  ['panel', 'Panel', 'Panels and cards that sit on the page canvas.'],
  ['popover', 'Popover', 'Menus, tooltips and other layers that open from a control.'],
  ['modal', 'Modal', 'Modals and drawers. They also use the scrim.'],
];

<div
  style={{
    display: 'grid',
    gridTemplateColumns: 'repeat(auto-fit, minmax(220px, 1fr))',
    gap: 'var(--he-spacing-6)',
    padding: 'var(--he-spacing-8)',
    background: 'var(--he-bg-app)',
    borderRadius: 'var(--he-corner-lg)',
    margin: 'var(--he-spacing-4) 0',
  }}
>
  {levels.map(([slug, name, use]) => (
    <div
      key={slug}
      style={{
        background: 'var(--he-bg-surface)',
        borderRadius: 'var(--he-corner-lg)',
        boxShadow: `var(--he-elevation-${slug})`,
        padding: 'var(--he-spacing-4)',
        minHeight: 120,
        color: 'var(--he-text-primary)',
      }}
    >
      <div style={{ fontWeight: 500 }}>{name}</div>
      <div style={{ color: 'var(--he-text-secondary)', marginTop: 'var(--he-spacing-1)' }}>{use}</div>
      <code style={{ display: 'block', marginTop: 'var(--he-spacing-3)' }}>{`--he-elevation-${slug}`}</code>
    </div>
  ))}
</div>

Toggle the theme in the toolbar to see the dark values. Dark shadows are stronger because the same light shadow would not show on a dark surface. See [Deviations from Figma](?path=/docs/foundations-deviations-from-figma--docs).

<Rule title="Nothing else casts a shadow">
  Buttons, inputs, badges, tabs and table rows have no shadow. Separate them with a border or a
  background step. Use the three tokens above and no custom `box-shadow`. The 0.x names
  `--he-shadow-card` and `--he-shadow-lift` point to panel and popover.
</Rule>
