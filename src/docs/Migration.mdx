# Migration from 0.x

1.0.0 is a restyle, not a rewrite. No export is removed, and no 0.x component is replaced by an alias to a differently shaped one. Old props still type-check. Most consumers need a version bump and a short check.

`npm run check:compat` builds the 0.4.5 declarations and type-checks every old component with its old props against the new one, and every old exported type against the new one. It is part of the 1.0.0 gate (planned: the script is not in the repo yet).

## What changes

- **Font.** Neue Haas Unica is gone. Inter is the UI face. Sentient (page titles) and IBM Plex Mono (identifiers) are unchanged. The Inter files and licence ship in the package.
- **Tokens.** Values come from Kevin's Figma variables. Colour roles in the 0.x names now point at the new semantic tokens, so they follow light and dark by themselves.
- **Exports.** None removed. New components are new exports (Checkbox, Radio, Field, Stepper, ChoiceCard, Toast, ThemeSwitch).
- **Look you will see.**
  - The primary button and other brand actions use the accent (Borealis, a pale lime) with Midnight text.
  - The page canvas is a light gray (`--he-bg-app`), and cards and tables are white or near white on top of it.
  - Tabs and nav items use a soft fill for the selected state, not a border or underline. The Tabs `underline` variant keeps its prop and is restyled.
  - Status badges carry a word and a dot, in four tones.
  - Dark mode has real status colours, not tints of the light ones.

Use the new names in new code. The kept spacing and radius scales have different values from the new ones. `--he-space-*` is not `--he-spacing-*`, and `--he-radius-sm` is 8px while `--he-corner-sm` is 4px.

</Rule>

## Steps for handle-v2

1. Bump `@procurus-ai/handle-elements` to 1.0.0.
2. Keep both imports: `fonts.css` and `styles.css`. Set `data-theme` on `<html>` as before.
3. Delete the `--he-font-sans` override in `globals.css`. The package now sets Inter itself, and the override would pin the old face.
4. Check the `.he-switch--checked` dark patch. If handle-v2 overrides it for dark mode, remove the patch and look at the Switch in dark. Keep it only if the Switch still looks wrong.
5. Run `npm run build` and look at one table page, one form page and one page in dark mode.
6. Search the code for the deprecated names above and move them to the new tokens over time. There is no deadline in 1.0.0.

## If something looks different

Check these first.

- A colour looks gray where it was white: the page now sits on `--he-bg-app`. Put cards on `--he-bg-surface`.
- Text looks slightly darker or lighter: five text tokens were adjusted for AA. See [Deviations from Figma](?path=/docs/foundations-deviations-from-figma--docs).
- Text wraps differently: the font changed, so check fixed-width columns and long labels.
